# โลโก้ประจำหมวดสินค้า

วางไฟล์โลโก้ในโฟลเดอร์นี้ แล้ว **ตั้งชื่อไฟล์ให้ตรงกับชื่อหมวด** — เท่านั้น
ระบบจะเอาไปแสดงในปุ่ม filter ทั้งหน้าภาพรวมและหน้าสต็อกให้เอง ไม่ต้องแก้โค้ด

```
หมวด "Dragon Ball"  →  public/logo/Dragon Ball.png
หมวด "Naruto"       →  public/logo/Naruto.png
```

## ไม่ต้องเป๊ะเรื่องพวกนี้

| เรื่อง | ตัวอย่างที่ใช้ได้ |
|---|---|
| ตัวพิมพ์เล็ก/ใหญ่ | `dragon ball.png` · `DRAGON BALL.png` |
| ช่องว่าง | `DragonBall.png` · `Dragon Ball.png` |
| สระละติน | `Pokemon.png` ใช้กับหมวด `Pokémon` ได้ |
| นามสกุล | `.png` `.jpg` `.webp` `.svg` |

## ข้อควรรู้

- **หมวดที่ยังไม่มีไฟล์โลโก้ จะแสดงเป็นข้อความตามเดิม** ไม่พัง
- โลโก้ควรเป็น **พื้นหลังโปร่งใส (PNG/SVG)** และเป็น **แนวนอน** — ระบบย่อให้สูง 16px กว้างไม่เกิน ~56px
- หลีกเลี่ยงโลโก้ที่มีขอบขาวรอบเยอะ เพราะจะทำให้ตัวโลโก้ดูเล็กในปุ่ม
- **ต้อง `git add` + commit ไฟล์ด้วย** ไม่งั้นจะขึ้นแค่ในเครื่องตัวเอง ไม่ขึ้นบนเว็บจริง

## เพิ่มแล้วไม่ขึ้น?

รายชื่อไฟล์ถูกสร้างตอน `npm run dev` / `npm run build`
ถ้าเพิ่มไฟล์ระหว่างที่ dev server รันอยู่ ให้ปิดแล้วเปิดใหม่ หรือสั่ง:

```bash
node scripts/gen-img-manifest.mjs
```
